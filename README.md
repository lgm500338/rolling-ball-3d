# Rolling Ball 3D

Vite + React + three.js로 만든 3D 공 굴리기 장애물 게임입니다.

## 로컬 실행

```bash
npm install --legacy-peer-deps
npm run dev
```

## 배포

Vercel에서 이 저장소를 가져오면 `vercel.json` 설정대로 빌드됩니다 (별도 환경 변수 필요 없음).
